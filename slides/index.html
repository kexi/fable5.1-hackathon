お題と制約

  • 19:42 に計画承認、締切 20:30。リポジトリは README だけ
  • Unity 6000.6.2f1 は入っている。ゲームの中身は未定
  • 人間はチャットで注文するだけ。実装・検証・デプロイは AI が実行
  • 途中で注文が増える: 死にゲー → Fable 級 → アセット凝って → 難易度選択 → Pages 公開

最初の 6 分で決めたこと

  • WebGL で配布（URL だけで遊べる）
  • URP Blank テンプレート、外部アセット禁止
  • ジャンル: 3 レーンのドッジ・ランナー（実装量が最小）
  • Unity プロジェクトは game/ に隔離
  • シーンは手で触らず SceneBuilder.Build() で生成

AI が Unity を動かす方法

  • 公式 Unity CLI 1.0.0-beta.8（Hub が入れてくれる ~/.unity/bin/unity）
  • com.unity.pipeline を入れると起動中の Editor が コマンド受付口になる
  • Unity 公式の Claude Code プラグイン unity@unity-agent-plugin（29 スキル）
unity projects create DodgeRunner --template com.unity.template.urp-blank
unity pipeline install --project-path game && unity open game
unity command eval 'DodgeRunner.EditorTools.SceneBuilder.Build(); return "ok";'
unity command editor_play && unity command screenshot --output shot.png
unity build game --target WebGL --execute-method DodgeRunner.EditorTools.Builder.BuildWebGL

開発ループ: 往復 1 秒未満

  • C# を書く → recompile → eval でシーン再生成
  • editor_play → eval で StartGame() → 状態を文字列で読む
  • screenshot を AI が見て、見た目のズレを直す
  • コンパイルエラーは Logs/Editor.log を grep
  • ビルドだけは Editor を閉じてバッチ実行（約 3 分）

ゲームの中身

  • A / D で 3 レーン移動、Space でジャンプ
  • 障害物 3 種: 橙=跳べる / 赤=ギリギリ / 紫=避けるしかない
  • 難易度: Haiku 4.5 / Sonnet 5 / Opus 5 / Fable 5.1
  • Fable 5.1 は 35% で全レーン封鎖。開始 4 秒で死ねる
  • 状態遷移は EditMode テスト 3 本で保証

ハマったところ

症状原因対処
Chrome で 1 FPS影 + FXAA + 色収差 + BloomBloom だけ残す
Pages で wasm が 404.gitignore の Build/ が dist/Build/ にも効く/Build/ に修正
タイトルの最終行が消えるuGUI Text の既定が TruncateOverflow に変更
スキル文書のフラグで失敗--caller を eval が拒否実測を優先

デプロイ方針

  • CI で Unity のライセンス認証はしない（時間と失敗リスク）
  • 手元で just build-web && just dist → dist/ を commit
  • GitHub Actions は dist/ を Pages にアップロードするだけ（アクションは SHA ピン）
  • WebGL は Gzip + decompressionFallback。Pages の Content-Encoding に依存しない
